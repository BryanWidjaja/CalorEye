CalorEye

nutrition tracker app that uses computer vision to detect food from photos and calculate their nutritional value.

Flow [WIP] :
1. Take photo of food
	-> goes into food detection model
2. Model produces the food item
3. System calculates nutritional info of product
4. System outputs nutritional info to user
5. System has built in calendar - tracker system for tracking calory / nutritional info
6. can give advice based on general / goals
